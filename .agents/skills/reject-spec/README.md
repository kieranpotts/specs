# Reject spec

Handles the `PROPOSED` → `REJECTED` transition.

Reverts the specification edits and merges the proposal document as a
permanent record of the decision.

## How to invoke

> Reject this proposal

> This proposal was not approved

> Reject user-session-timeout

> Reject 42

## Recommended models

A mid-tier model is sufficient for this skill. The steps are procedural, but
reverting the specification edits precisely requires a bit more effort.
